# استديو تنفيذ شيلات ليالي الانس

موقع عربي متجاوب لعرض أعمال الاستديو وباقاته واستقبال طلبات العملاء عبر واتساب.

## النشر عبر GitHub Pages

1. افتح **Settings** في المستودع.
2. اختر **Pages** من القائمة الجانبية.
3. في **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم اضغط **Save**.
5. بعد اكتمال النشر سيكون الرابط المتوقع: https://studio-0506091604.github.io/layali-al-ans-studio/

## إدارة المحتوى

زر «إدارة المحتوى» أسفل الصفحة يتيح إضافة الأعمال والباقات وتعديلها وحذفها واستيراد/تنزيل نسخة احتياطية. النسخة الحالية تحفظ التغييرات في `localStorage` للمتصفح الحالي فقط؛ لا تحفظها على الخادم ولا تعرضها تلقائياً للزوار الآخرين. لا توجد حماية دخول في هذه النسخة. لإدارة مشتركة وآمنة من أي جهاز، يلزم ربط الموقع بخادم وقاعدة بيانات ونظام دخول.

## ملفات الصوت

ارفع ملفات MP3 إلى المستودع أو استضافة ملفات، ثم من لوحة إدارة المحتوى ضع رابط الملف في خانة رابط الصوت. لا تتضمن النسخة الحالية ملفات الصوت الأصلية.
